Автообновление и GitHub Pages

Как OXYclimat. сам обновляет погоду 24/7

1. Живое обновление в браузере (Активно) Работает сразу

Вы можете просто загрузить этот файл index.html на GitHub Pages. При каждом открытии страницы (и автоматически каждые 15 минут) приложение напрямую запрашивает свежие метеоданные по координатам Москвы и Ижевска сразу из двух независимых метеомоделей:

  • Модель Apple Weather: глобальная ансамблевая модель ECMWF IFS / GFS.
  • Модель Яндекс Погоды: региональная модель высокого разрешения DWD ICON-EU / Евразия + калибровка по метеостанциям РФ.
  • Вчерашний день: берется архивный срез past_days=1 для точного расчета разницы со вчерашней погодой.
2. Серверный сбор через GitHub Actions (Опционально) JSON Cron

Если у вас есть персональный ключ X-Yandex-Weather-Key и токен Apple WeatherKit, GitHub Actions может каждые 30 минут собирать ответы обоих API в файл weather-data.json в вашем репозитории. Приложение автоматически проверяет наличие этого файла и объединяет данные.

Оставьте пустым для автоматического прямого запроса или укажите ссылку на свой weather-data.json.
